# IoC Extractor

Настольное приложение (Python + Tkinter) для извлечения индикаторов компрометации
из документов и импорта их в OpenCTI.

- **Входные форматы:** PDF (с текстовым слоем), DOCX, CSV/TSV, TXT (а также LOG, JSON, XML, HTML, EML, MD).
- **Типы IoC:** URL, домены, IP (IPv4/IPv6), email, хэши (MD5, SHA-1, SHA-256, SHA-512).
- **Экспорт:** TXT и CSV — все IoC одним файлом или отдельный файл на каждый тип.
- **OpenCTI:** импорт в отдельный черновик (Draft workspace) для анализа перед добавлением в базу.

## Запуск

Готовый exe: `dist\IoCExtractor.exe` (Python не нужен). Файлы можно передать аргументами
или перетащить на значок exe: `IoCExtractor.exe report.pdf`.

Из исходников (Python 3.10+):

```bash
pip install -r requirements.txt
```

```bash
python main.py
```

## Сборка exe

```bash
build_exe.bat
```

Скрипт создаёт `.venv`, ставит зависимости и PyInstaller и собирает однофайловый
`dist\IoCExtractor.exe` без консольного окна.

## Как работает извлечение

1. **Рефанг.** Обезвреженные записи приводятся к обычному виду: `hxxps[:]//evil[.]com` → `https://evil.com`,
   `user[at]mail(.)ru` → `user@mail.ru` (поддерживаются `[.]`, `(.)`, `{.}`, `[dot]`, `[:]`, `[@]`, `[at]`, `hxxp`, `h**p`, `fxp`).
2. **Склейка переносов** (для PDF и TXT). В PDF индикаторы часто разорваны переносом строки — эвристики склеивают:
   - хэш, разрезанный на две строки (если суммарная длина = 32/40/64/128);
   - домен или URL, перенесённый по дефису (`credit -` / `bestsale[.]ru`, `brostoplookingformyc2-` / `21003[.]portmap[.]io`);
   - хвост URL на следующей строке (`…/img_test.jp` / `g?14441723`).
3. **Поиск** регулярными выражениями с проверками: домены и хосты URL — по списку TLD IANA,
   IP — через `ipaddress`, хэши — по длине. Хэши и домены внутри URL не дублируются отдельно
   (если нужно — включите «Добавлять домены/IP из URL»).
4. **Фильтры ложных срабатываний.** Необезвреженные «домены» вида `script.py`, `archive.zip`,
   `510,100.com`, `г.Москва` отбрасываются; обезвреженные (`[.]`) — сохраняются всегда.
   Белый список («Исключения…») убирает домены (с поддоменами, URL и email на них), IP и подсети.
   По умолчанию в нём шапка писем Минобрнауки (`minobrnauki.gov.ru`) и `dr.web`.

Опция «Только обезвреженные» оставляет лишь URL/домены/IP/email, записанные в документе
в обезвреженном виде, — удобно для бюллетеней, где все сетевые IoC обезврежены.

В таблице: двойной клик — подробности и контекст (строка документа), `Del` — удалить
из списка, `Ctrl+C` — копировать значения, клик по заголовку — сортировка.

## Экспорт

- **TXT, один файл** — разделы `# URL (N)`, `# Домен (N)`, … по одному значению на строку.
- **TXT по типам** — `<имя>_url.txt`, `<имя>_domain.txt`, `<имя>_ip.txt`, `<имя>_email.txt`, `<имя>_hash.txt`.
- **CSV** — разделитель `;`, кодировка UTF-8 с BOM (открывается в Excel с русской локалью).
  Колонки: `type; subtype; value; value_defanged; count; sources; context`.
- Флажок «Экспортировать в обезвреженном виде» записывает `hxxps[:]//evil[.]com` вместо рабочих ссылок.

## Импорт в OpenCTI

Требуется OpenCTI **6.5+** (черновики) и API-токен пользователя с правом создавать знания
(`KNOWLEDGE_KNUPDATE`). Токен — в OpenCTI: профиль → *API access*.

Кнопка «Импорт в OpenCTI (Draft)…»:

1. создаёт черновик (`draftWorkspaceAdd`);
2. в контексте черновика (заголовок `opencti-draft-id`) создаёт наблюдаемые:
   `Url`, `Domain-Name`, `IPv4-Addr`/`IPv6-Addr`, `Email-Addr`, `StixFile` (с хэшем) —
   с заданным score и, по желанию, с индикаторами (`createIndicator`);
3. по желанию создаёт отчёт (Report) со всеми импортированными объектами.

Пока черновик не подтверждён (*Validate*), в основную базу ничего не попадает.
Открыть его: **Data → Import → Drafts**.

Настройки (URL, параметры, исключения) хранятся в `%APPDATA%\IoCExtractor\settings.json`.
Токен сохраняется туда только при включённом «Запомнить токен» — в открытом виде.

## Ограничения

- Сканы PDF без текстового слоя не поддерживаются (нужен OCR); `.doc` (Word 97-2003) — пересохраните в `.docx`.
- Если PDF при извлечении вставил пробел внутрь IoC (например, `JA V A` вместо `JAVA`),
  значение обрывается на пробеле — проверяйте длинные URL по колонке «Контекст».
